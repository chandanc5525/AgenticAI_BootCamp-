# Python for AI Engineering

**Module 01 | Agentic AI Bootcamp**

Build strong Python programming foundations for developing Generative AI applications, intelligent agents, and production-ready AI systems.

## Overview

Python is the primary programming language used across modern AI engineering. Before developing LLM-powered applications, RAG pipelines, and autonomous AI agents, it is important to understand Python programming concepts and their practical applications.

This module provides a structured, hands-on approach to learning Python specifically from an AI engineering perspective.

The focus is on writing clean, reusable, modular, and maintainable Python code that can be extended into real-world AI applications.

## Learning Objectives

By completing this module, you will be able to:

- Understand Python programming fundamentals.
- Work with built-in data structures and collections.
- Write reusable functions and modular programs.
- Apply Object-Oriented Programming (OOP).
- Understand exception handling and debugging.
- Work with Python modules and packages.
- Read and write files using Python.
- Understand decorators, iterators, and generators.
- Manage Python environments and dependencies.
- Develop a programming foundation for AI and Agentic AI applications.

## Development Environment Setup

### Prerequisites

- Python 3.12 or later
- Visual Studio Code
- Git
- Basic computer programming knowledge

### 1. Clone the Repository

```bash
git clone https://github.com/chandanc5525/AgenticAI_BootCamp-.git
```

### 2. Navigate to the Module

```bash
cd AgenticAI_BootCamp-/01_python_for_ai_engineering
```

### 3. Create a Virtual Environment

Using uv:

```bash
uv venv
```

### 4. Activate the Environment

Windows:

```bash
.venv\Scripts\activate
```

Linux / macOS:

```bash
source .venv/bin/activate
```

### 5. Install Required Libraries

```bash
uv pip install numpy pandas matplotlib jupyter
```

### 6. Launch Jupyter Notebook

```bash
jupyter notebook
```
