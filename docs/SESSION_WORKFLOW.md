# How we will process each session

1. State learning outcomes and prerequisites.
2. Explain the concept in simple language.
3. Describe architecture and data flow.
4. Explain relevant mathematics where useful.
5. Implement a minimal example from scratch where appropriate.
6. Explain important code line by line.
7. Run the example and inspect outputs.
8. Give one guided exercise and one independent assignment.
9. Review against acceptance criteria.
10. Update progress and prepare the next session.

Copy `templates/SESSION_TEMPLATE.md` into the active session folder for a detailed session record.
